== What Is a Red Hat QuickStart?

A Red Hat QuickStart is a packaged, demo-ready proof-of-concept accelerator. Instead of walking a customer through a slide deck, you stand up a working, customer-relevant scenario in minutes. That turns an abstract pitch into something the customer can see running.

For a Solution Architect, this changes the sales conversation. You lead with a live demo, show real behavior on Red Hat OpenShift and Red Hat OpenShift AI, and let the customer react to a working system. The result is a shorter, more credible path from first conversation to proof of value.

== The AI Quickstarts Catalog

The AI Quickstarts catalog is where you find and match QuickStarts to a customer use case. Browse it at https://docs.redhat.com/en/learn/ai-quickstarts[the AI Quickstarts catalog^] to see what's available and which scenario each one addresses. When a customer describes a problem, the catalog is your starting point for picking the QuickStart that fits.

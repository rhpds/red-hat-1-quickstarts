# Module 3: AI Quickstart IT Self Service — Selling the Demo

### Brief Overview

This module puts participants in front of an already-deployed AI Quickstart IT Self Service instance, built by the field around a speeding-up-ticket-resolution use case closer to real customer scenarios. Participants use the pre-deployed instance and draw on existing field-provided talking points and demo material to build a customer-facing narrative.

### Audience and Time

- **Target personas:** Red Hat Solution Architects, Red Hat One attendees
- **Prerequisites for this module:** Module 1 (what a QuickStart is, catalog navigation); access to the pre-deployed AI Quickstart IT Self Service instance in the tenant namespace
- **Estimated duration:** 20 minutes

### Learning Objectives

- Demonstrate the AI Quickstart IT Self Service to a customer audience using a pre-deployed instance
- Identify how this QuickStart speeds up IT ticket resolution and the customer use case it addresses
- Apply existing field-provided talking points and demo material to narrate the demo

### Lab Structure

| Section | Title | Duration |
|---------|-------|----------|
| 1 | Orientation to the pre-deployed AI Quickstart IT Self Service environment | 5 min |
| 2 | Walk through the ticket-resolution workflow end-to-end | 10 min |
| 3 | Customer demo framing using existing field talking points | 5 min |

### Detailed Steps

1. Confirm access to the pre-deployed AI Quickstart IT Self Service instance in the participant's tenant namespace.
2. Tour the deployed environment (UI/console, key components) without redeploying anything.
3. Run through the ticket-resolution workflow as a customer would experience it.
4. Review the existing field-provided talking points and demo material for this QuickStart.
5. Practice narrating the demo using that material, tying it to a real customer IT service-desk scenario.

### Key Takeaways

- The AI Quickstart IT Self Service speeds up ticket resolution, addressing a use case grounded in real field experience
- This QuickStart already has field-tested talking points and demo material — reuse it rather than reinventing it
- Running the demo well is about narration and framing, not deployment steps

### Infrastructure Notes

Requires the AI Quickstart IT Self Service pre-deployed per tenant namespace via GitOps ahead of the session. No deployment steps performed by participants.
